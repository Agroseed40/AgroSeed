# Minimum questions for AgroSeed

Ask the client only these items to begin connecting the core live flows:

1. **GoDaddy:** Which domain should the store use, and can you add the developer to the GoDaddy hosting account so the app can be configured?
2. **Online payments:** We can use Razorpay for the website payments. Please create/verify a Razorpay business account for AgroSeed and link the business bank account for settlements. Which methods should customers see: UPI only, or UPI plus cards/net banking? The developer will connect it to the site.
3. **Customer sign-in:** Should customers be able to place orders as guests, or must they sign in with a text-message code? Guest checkout is available; phone-code sign-in needs an SMS service and may have per-message charges.

The client does **not** need to choose a database or provide product details now. I can select/configure the database for GoDaddy; staff will enter product-specific pack, price, stock, and photos when uploading each item. Shipping rules and the customer support number can be added later in Admin. Support phone/email fields are already editable there.

They do not need to give us a UPI ID for automatic payment confirmation. Do not ask them to send GoDaddy passwords, Razorpay passwords, API keys, webhook secrets, or bank credentials in chat/email. Have the account owner invite the developer or enter service secrets into the hosting provider's protected settings.
